BUILDING

Still in Vietnam. Still at my desk. A self-hosted TLS certificate authority — implementing ACME/RFC 8555 from scratch, because reading the Let's Encrypt docs wasn't enough. I needed to feel every byte of the handshake.

Also: a static HTML5 game serving pipeline. Turns out "just put the files on a server" hides an enormous amount of nuance — root-relative paths, base tags, Service Workers, the entire JS boot process. I'm mapping all of it.

And Minecraft Bedrock add-ons. Everyone needs a project that doesn't matter.
